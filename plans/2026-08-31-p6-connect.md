# P6 — connect + Connections section + snapshots (#197)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:test-driven-development
> per task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** The argued links. Notes stop being islands (#4): after a note
lands, `connect` proposes links with one-clause arguments, the owner
approves or strikes each at the digest, and only then does the loop
rewrite the note with a `Connections` section — snapshotted first,
because the vault is iCloud and the snapshot is the only undo.

**Owner decisions (batched 2026-08-31, session 076):**

- Connect runs AFTER kept (option a). The note lands exactly as today;
  connect proposes on the landed note; approval snapshots + appends the
  section and records `connected` as the item's final state. "None" or a
  parked ask leaves the item at `kept`. Matches the verb table ("input:
  accepted note") and keeps the note live in vault/search either way.
- Warm-ups #199 and #201 fold into this branch. #201 is gated: the
  before/after on the saved drafts in `~/.ytk/evidence/drafts/` is shown
  to the owner before the change counts as done.
- Candidate guesses accepted: cosine floor 0.60 (corpus NN p50 0.560,
  the floor sits just above background similarity), below
  NEAR_DUP_BASELINE 0.90, cap 5, one Sonnet structured call writes all
  arguments. Re-sized later from strike/approve answers.

**Spec:** `docs/architecture/curator-engine.md` — Verbs (connect row),
Asks (connections kind: "approve these links / strike some / none", if
parked: none), Ledger (snapshots table), "AI links are worthless unless
the owner made them".

**Structural exclusions:** connect triggers only inside the landing path
(`curator._land` callers), so the 754 grandfathered kept items can never
be picked up — no selector over `kept` exists. store.py stays read-only
(links live in notes; bulk generated links degrade retrieval, which is
why the owner approves each one). No re-index after the Connections
append: youtube embeddings come from metadata+enrichment+transcript, not
the note file, and re-embedding link titles into web docs would move the
#85 gate for zero retrieval value.
