How this fits together

Full doc with example setups: docs/settings.md in the repo.

There is one tag namespace — the tags: frontmatter on every note. Three settings touch it in different ways:

  • hub tags — the chips you tap in /inbox at queue time. An input shortcut: tapped chips are written into the note's tags, same field as everything else. Vocabulary of intent (build-idea, reference), not topics.
  • enrichment tags — the ~400-strong open vocabulary Haiku coins per note. Not configured here; gardened after the fact in /tags, whose merge decisions hold forever via the alias map.
  • interest tags (Ingest filters) — the only one that can reject content: non-empty means a video is refused unless enrichment tagged one of these. Empty = allow all, curate in the queue instead.

Interest model settings shape ytk profile synthesis; map color rules are consumed by /map; fetch cadence throttles the auto-pull that runs on page loads.
